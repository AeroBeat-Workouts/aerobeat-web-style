# Gameplay visual-role tokens

`aerobeat-web-style` publishes generic CSS custom properties for left, right, guard, obstacle, receptor, safe-cell, background, feedback, hatch, and dim treatments. They are visual defaults for DOM components and serializable theme projection.

The token package does not define target timing, judgement, recipes, calibration, session behavior, converter settings, grid evidence, or gameplay layout policy. WebGL receives explicit serializable theme values through the public theme contract; it does not read the document cascade or import style internals.

Obstacles use both red color and hatch treatment. Stable role names let athlete themes replace colors without changing gameplay or semantic icon IDs.
